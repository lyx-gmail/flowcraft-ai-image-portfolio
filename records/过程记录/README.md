# 过程记录说明

完整批量定义、图片规划和生成回执已归档在本地。公开仓库保留可阅读的[成品与验收摘要](../合格成品清单.md)及[实际运行记录](../实际运行记录.md)。原始批量定义记录以下信息：

- `mode`：生成类型（hero 主图 / detail 详情 / ad 广告）；
- `brief`：该张图的构图与场景要求（一图一场景，禁止拼图）；
- `policy`：该张图的文字边界，即「已确认文字策略」——标题与卖点语言、哪些包装文字保留、禁止新增什么。

这些文件就是当次生产的验收标准来源：先生成定义，再逐张提交，最后按定义逐张验收。

请求编号、耗时、状态与最终提示词保存在本地归档，便于复盘；公开仓库不再收录机器运行文件。凭据与素材 base64 不写入这些证据记录。
