# 过程记录说明

每个商品目录下保存的是本次生产使用的「批量定义」文件（`批量-五张.json` 或 `详情NN.job.json`）：

- `mode`：生成类型（hero 主图 / detail 详情 / ad 广告）；
- `brief`：该张图的构图与场景要求（一图一场景，禁止拼图）；
- `policy`：该张图的文字边界，即「已确认文字策略」——标题与卖点语言、哪些包装文字保留、禁止新增什么。

这些文件就是当次生产的验收标准来源：先生成定义，再逐张提交，最后按定义逐张验收。

请求编号、耗时与状态保存在 [`../回执/`](../回执) 的 receipt JSON；最终提交给模型的提示词与摘要保存在对应的 plan JSON。凭据与素材 base64 不落盘。
